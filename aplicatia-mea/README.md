# Voyago – aplicația React (aplicatia-mea)

Prima instalare (adaugă și dependențele noi, în versiunile compatibile cu proiectul):

    npm install
    npm install react-router-dom leaflet
    npm install -D vitest @testing-library/react @testing-library/dom @testing-library/jest-dom jsdom

Comenzi: `npm run dev`, `npm run test:run`, `npm run lint`, `npm run build`, `npm run preview`.

Site-ul vechi (HTML/CSS/JS) rămâne în folderul părinte, neschimbat.
